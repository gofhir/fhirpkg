- `quantity-constraints` (deliberate): SimpleQuantity and MoneyQuantity are profiles of Quantity (StructureDefinition.derivation constraint), not types. The HL7 validator rejects them as type names: as(SimpleQuantity) fails with 'The type FHIR.SimpleQuantity is not valid', like an invented name (validator_cli 7.0.2, R4, R4B and R5).
- `metadata-resource-r4` (deliberate): R4 MetadataResource is a logical model (StructureDefinition.kind logical): structuredefinition.html says a logical model is not a type an instance has. Decided by the user on 02-11-2026 (ADR-004 D2): excluded, by the specification (fhirpath.html: the FHIR namespace holds primitives, data types and resources; no R4 resource derives from it). validator_cli 7.0.2 accepts as(MetadataResource) but also as(Event) and as(FiveWs), so it measures the name of a non-profile definition, not a type.
- `data-type-r4b` (deliberate): R4B hl7.fhir.r4b.core has the abstract type DataType (a specialization with a snapshot, base of the complex types) and gofhir/models r4b does not list it; R5 models does. The validator accepts as(DataType) in R4B.
- `abstract-type-paths` (deliberate): The paths of an abstract type (Resource.id, DomainResource.text, DataType.id, BackboneType.id, CanonicalResource.name...) are in the snapshot of its StructureDefinition, a specialization. models does not generate them.
- `nested-backbone-type` (models-defect): models types the nested elements of a data type as BackboneElement. The snapshot gives them Element (Timing.repeat, Dosage.doseAndRate, ElementDefinition.*): the model says timing.repeat.is(BackboneElement), the specification does not.
- `no-targets-on-choice-variants` (models-defect): models gives no ReferenceTargets for the variants of an element with several types (productReference, subjectCanonical...), although each variant keeps the targetProfile of its type.
- `no-targets-on-codeable-reference` (models-defect): models gives no ReferenceTargets for CodeableReference elements (R4B and R5), which carry targetProfile like a Reference.
- `repeated-target` (models-defect): models repeats a target in the list: Media.device is [Device, DeviceMetric, Device] because its snapshot lists Device in two targetProfile; fhirpkg lists each type once.
